# Domain docs

採單一領域配置。

## Before exploring

- 閱讀根目錄 GLOSSARY.md。
- 閱讀 docs/adr/ 中與目前工作相關的決策。
- 文件不存在時直接繼續，不預先建立空白文件。

## Vocabulary and decisions

- 描述領域概念時，沿用 GLOSSARY.md 的術語。
- 發現術語缺口時，交由 domain-modeling 釐清。
- 提案與現有 ADR 衝突時，明確指出衝突與重新評估理由。
- domain-modeling 在術語確定或確有決策需要記錄時，才建立 GLOSSARY.md 或 ADR。
