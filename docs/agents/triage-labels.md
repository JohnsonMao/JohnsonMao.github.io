# Triage labels

| Role | GitHub label | 意義 |
| --- | --- | --- |
| needs-triage | needs-triage | 待維護者評估 |
| needs-info | needs-info | 待回報者補充資訊 |
| ready-for-agent | ready-for-agent | 規格完整，可交給 AI 執行 |
| ready-for-human | ready-for-human | 需要人工實作 |
| wontfix | wontfix | 不予處理 |

Skill 提到分流角色時，使用對應的 GitHub label。
