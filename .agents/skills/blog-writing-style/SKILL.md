# 部落格寫作風格指南

根據既有文章分析總結的個人寫作風格，用於保持部落格內容的一致性和品質。

## 何時使用

- 📝 撰寫新的部落格文章
- ✏️ 編輯現有文章以保持風格一致
- 🔍 檢查文章是否符合個人風格標準
- 👥 指導他人按照您的風格投稿

## 寫作風格核心特徵

### 1️⃣ 語調與人設

**親切友善、平易近人的技術教育者**

- ✅ 使用第一人稱「我」拉近距離
- ✅ 親身經歷和真實感受
- ✅ 非正式、對話式的語句
- ✅ 謙遜開放的態度
- ✅ 邀請讀者互動和指正

**範例開場：**
> 我是毛毛，因為這波疫情影響下，讓我多了許多時間可以好好投資自己...
> 如果有發現內容有誤，也請您不吝指教，感謝。

---

### 2️⃣ 文章結構

遵循 **前言 → 核心內容 → 總結** 的清晰架構

```
📌 Front Matter (Metadata)
├── title: 有表現力的標題
├── description: 精準的一句話摘要
├── pubDate: 發布日期
├── tags: 相關標籤
└── image: 首圖

📝 正文
├── 前言（導入主題）
├── 核心內容（分層標題）
│   ├── 背景說明
│   ├── 核心概念
│   └── 實踐應用
└── 總結（收尾與展望）
```

---

### 3️⃣ 概念講解方式

**從「為什麼」開始，用類比轉化複雜概念**

- 先說明**問題或痛點**
- 解釋**解決方案的必要性**
- 用**日常生活類比**降低理解門檻
- 配合**圖表或示意圖**視覺化

**範例類比：**
> 命令式 vs 聲明式編碼
> - 命令式：「老師口渴，命令同學去裝水」（需指定每一步）
> - 聲明式：「老師說喉嚨乾，同學自動遞水」（只聲明需求）

---

### 4️⃣ 視覺化與圖表

- 📸 大量使用 **Imgur 圖片**做視覺說明
- 🎬 插入 **GIF 動畫**展示操作流程
- 📊 用**表格**整理複雜資訊
- 🔗 包含**截圖和箭頭標註**
- 🖼️ 每篇文章都有**首圖**

---

### 5️⃣ 系列化教學

適合創建**多篇連貫的系列文章**

- 循序漸進地從基礎到進階
- 明確標註前置知識清單
- 每篇獨立但相互關聯
- 例如：30天系列、React 完整指南、TypeScript 系列

---

### 6️⃣ 實用導向

- ✅ 提供**具體的操作步驟**
- ✅ 分享**實用工具和快捷鍵**
- ✅ 列舉**常用推薦清單**（如 VS Code 套件）
- ✅ 引導**邊學邊做**的實踐方式
- ✅ 包含**外部參考資料連結**

---

### 7️⃣ 語言與措辭

- 📍 使用**繁體中文**（台灣用語）
- 🎯 標題富有表現力和趣味性
  - ✅ 「工欲善其事，必先利其器」
  - ✅ 「歡迎來到網頁這個世界」
  - ❌ 「HTML 介紹」
- 🔤 適當使用**標點符號**增加節奏感
- ⚡ 段落簡潔，避免冗長句子

---

## 寫作檢查清單

在發布前使用此清單確保文章符合風格：

### 內容層面
- [ ] 有吸引人的引入段落（前言）
- [ ] 清楚解釋「為什麼」這個主題重要
- [ ] 使用至少一個日常類比或例子
- [ ] 概念由簡至繁，循序漸進
- [ ] 有明確的總結段落

### 結構層面
- [ ] 使用適當的標題層級（H2、H3）
- [ ] 段落長度適中（避免過長）
- [ ] 重點內容用粗體或清單標示
- [ ] 相關概念分組聚集

### 視覺層面
- [ ] 包含至少 3-5 張相關圖片或圖表
- [ ] 有首圖（Open Graph 圖像）
- [ ] 複雜內容用表格或圖示表現
- [ ] 圖片都有相關的標題或說明

### 互動層面
- [ ] 使用「我」來建立連結
- [ ] 邀請讀者互動或反饋
- [ ] 提供參考資料或延伸閱讀
- [ ] 若有錯誤，主動邀請讀者指正

### Front Matter
- [ ] 標題有表現力（不只是主題名）
- [ ] description 是完整的一句話摘要
- [ ] 包含相關的 tags
- [ ] 有合適的首圖 URL

## 實用模板

### 文章開頭模板

```markdown
---
title: "具有吸引力的標題"
description: "一句話總結這篇文章的內容"
pubDate: "YYYY-MM-DD"
image: "https://i.imgur.com/xxxxxx.png"
tags:
  - tag1
  - tag2
series: optional-series-name
---

![首圖](https://i.imgur.com/xxxxxx.png)

## 前言

[說明個人經歷或寫作動機，2-3 句話]

[為什麼這個主題重要？]

## [核心內容標題]

[循序漸進的詳細說明]

## 總結

[回顧重點，展望未來或邀請互動]
```

### 概念解釋模板

```markdown
### [概念名稱]

**簡單定義：** [一句話解釋]

**為什麼重要：** [說明實際應用或問題]

**類比說明：**
> [日常生活中的類比例子，幫助理解]

**實際例子：**
- 場景 1: [具體應用]
- 場景 2: [具體應用]

![相關圖示](url)
```

### 系列文章Front Matter模板

```markdown
---
series: series-name-slug
title: "Series Title - 完整標題"
description: "這篇文章在系列中的角色"
pubDate: "YYYY-MM-DD"
---

<!-- 系列文章會自動聚集 -->
```

## 常見問題

**Q: 文章應該有多長？**
A: 根據內容深度，通常 800-2000 字。系列文章可以更短（500-800 字），單篇深度文章可以更長（2000+ 字）。

**Q: 多少圖片才夠？**
A: 至少 3-5 張相關圖片/圖表。視覺化是您風格的重要特色。

**Q: 可以用其他語言嗎？**
A: 保持繁體中文為主。技術術語和代碼保持英文。

**Q: 系列文章如何標記？**
A: 在 Front Matter 加入 `series: series-name-slug`，網站會自動聚集。
