## 標題風格指南

### ✅ 好的標題特徵
- 有表現力且資訊豐富
- 包含關鍵詞便於搜索
- 引起好奇或興趣
- 長度適中（5-10 字最佳）

### 標題模式

**模式 1：古諺/成語開頭**
```
「工欲善其事，必先利其器」—— 前言與工具介紹
「歡迎來到網頁這個世界」—— 認識網頁架構
```

**模式 2：框架/技術名 + 概念**
```
React - 簡介
React - 組件與模組
React - 生命週期
```

**模式 3：系列編號 + 主題**
```
Day.1 「工欲善其事，必先利其器」
Day.2 「歡迎來到網頁這個世界」
```

**模式 4：情感/問題導向**
```
從 0 開始學 React
為什麼要學 TypeScript
我的 JSDC 2021 參與心得
```

## 描述文案模板

### Front Matter Description 模板

**短形式（50-80 字）：**
> 介紹 React 的背景、優點以及為什麼要學習 React，包括聲明式編碼與虛擬 DOM 的核心概念。

**中形式（80-120 字）：**
> 深入了解 React 中的組件（Component）與模組（Module）化開發，以及如何使用開發者工具進行調試。本篇將詳細解釋這兩個核心概念在提升開發效率中的重要作用。

## 標籤系統

### 常用標籤集合

```
// 技術標籤
- javascript / typescript / react / vue / node
- html / css / webpack / vite
- astro / next / nuxt

// 系列標籤
- it-ironman
- series-name

// 內容類型
- tutorial / guide / tips / journal
- conference / learning-note / project-update

// 特殊標籤
- beginner-friendly / deep-dive
- performance / security / accessibility
```

### 標籤最佳實踐
- 每篇文章 2-4 個標籤
- 混合技術標籤和內容類型標籤
- 系列文章應有共同標籤
- 避免過於具體的標籤
