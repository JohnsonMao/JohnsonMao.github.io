# 部落格寫作風格 SKILL

這是一個個人化的寫作風格指南，幫助您在撰寫部落格文章時保持一致的風格和品質。

## 📚 檔案結構

```
blog-writing-style/
├── SKILL.md                          # 主技能檔案（核心指南）
├── README.md                         # 您正在閱讀的這個文件
│
├── references/                       # 詳細參考資料
│   └── style-analysis.md            # 風格詳細分析（背景知識）
│
└── templates/                        # 實用模板和工具
    ├── article-template.md          # 文章開頭模板
    ├── checklist.md                 # 發佈前檢查清單
    └── quick-reference.md           # 快速查詢表
```

## 🎯 快速開始

### 場景 1：寫新文章
1. 打開 [article-template.md](./templates/article-template.md)
2. 複製模板到新文章
3. 參考 [SKILL.md](./SKILL.md) 的「寫作風格核心特徵」
4. 完成後使用 [checklist.md](./templates/checklist.md) 檢查

### 場景 2：編輯現有文章
1. 查看 [SKILL.md](./SKILL.md) 的「寫作檢查清單」
2. 根據清單逐項檢查文章
3. 參考 [style-analysis.md](./references/style-analysis.md) 了解風格細節

### 場景 3：尋找特定資源
- **需要類比？** → [quick-reference.md](./templates/quick-reference.md) 的「常用類比集合」
- **需要標題靈感？** → [quick-reference.md](./templates/quick-reference.md) 的「標題風格指南」
- **需要深入了解？** → [style-analysis.md](./references/style-analysis.md)

## 🎨 寫作風格總結

### 7 個核心特徵

1. **親切友善** - 使用第一人稱，拉近距離
2. **結構清晰** - 前言 → 核心 → 總結
3. **善用類比** - 用日常例子解釋技術
4. **視覺豐富** - 3-5 張圖片 + 表格
5. **系列化教學** - 循序漸進的多篇文章
6. **實用導向** - 具體步驟、工具、快捷鍵
7. **開放態度** - 邀請互動和反饋

### 核心檢查項
- [ ] 使用「我」建立連結
- [ ] 解釋「為什麼」，而不只是「是什麼」
- [ ] 包含至少 1-2 個日常類比
- [ ] 有 3-5 張相關圖片
- [ ] 提供具體可應用的內容
- [ ] 有明確的總結和互動邀請

## 💡 使用建議

### 最佳實踐
1. **定期檢查** - 每寫 2-3 篇後重讀 SKILL.md
2. **記住模板** - 熟悉後可以手寫而不需複製
3. **參考範例** - 查看既有的優秀文章作為參考
4. **持續改進** - 根據反饋調整風格

### 常見問題
- **Q: 可以打破這些規則嗎？**
  A: 可以，但要有意識地做出選擇。規則是指導，不是絕對限制。

- **Q: 所有文章都要有系列嗎？**
  A: 不需要。單篇深度文章或心得也很適合。

- **Q: 圖片太多會不會太累贅？**
  A: 不會。視覺化是您風格的重要特色，讀者喜歡看圖。

- **Q: 前言要多長？**
  A: 2-3 句話即可。重點是建立個人連結和說明為什麼寫這篇。
